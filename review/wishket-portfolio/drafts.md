# 위시켓 등록 설명 초안

아래 문안은 공개 포트폴리오의 역할·기간·기술을 토대로 정리한 등록 초안입니다. 고객사 비공개가 필요한 경우 해당 이름은 노출하지 않습니다.

## VIVACERIA

- 기간: 2026
- 유형: 웹 쇼핑몰 / 브랜드 커머스
- 설명: 프리미엄 수제·보석 도장 브랜드의 자사몰로, 브랜드 스토리와 카테고리 탐색, 맞춤 옵션형 상품 상세, VIP·이벤트·뉴스레터까지 구매 흐름을 구성했습니다.

## Grovi

- 기간: 2025–2026
- 유형: 웹·모바일 쇼핑몰 / 리빙 커머스
- 설명: 리빙 플랜트와 홈 리빙 상품을 위한 모바일 퍼스트 커머스입니다. 카테고리 숏컷, 베스트·신상·세일, 상품 목록과 상세의 구매 동선을 정리했습니다.

## mimmua!

- 기간: 2025–2026
- 유형: Shopify 웹 스토어
- 설명: 글로벌 스킨케어 D2C 스토어로 Shopify 테마와 커머스 UX를 구성하고, 제품 라인 탐색, 퀵 애드, PayPal 결제와 해외 배송 안내를 연결했습니다.

## 경희대학교 일반대학원 미디어학과 웹사이트

- 기간: 2025–2026
- 유형: WordPress 웹사이트
- 설명: 지원자·재학생·외국인 사용자가 공지와 학과·입시 정보를 쉽게 탐색하도록 WordPress 블록 테마, 다국어 구조, 커스텀 플러그인을 구축했습니다.

## Sign Bridge

- 기간: 2025–2026
- 유형: Android 앱
- 설명: 수어와 음성이 섞인 대화를 돕는 Android 앱입니다. 수어 인식·출력, 음성 인식과 TTS를 연결해 양방향 소통 흐름을 구현했습니다.

## News Network (NN)

- 기간: 2025–2026
- 유형: 웹·API 뉴스 플랫폼
- 설명: 사용자 웹, 관리자, API를 하나의 구조로 설계한 뉴스 플랫폼입니다. 주제별 피드, 기사 상세, 운영 도구와 API를 풀스택으로 구현했습니다.

## N.MOOD 쇼핑몰 · 비건 쇼핑몰 · 보니벨로 쇼핑몰

- 기간: 2024
- 유형: 웹 쇼핑몰
- 설명: 브랜드별 쇼핑몰과 운영 도구를 구축했습니다. 상품 탐색과 구매 흐름, 반응형 화면, 관리 기능을 프로젝트 요구에 맞춰 구성했습니다.

## KLAP4U Learn EPS-TOPIK with AI

- 기간: 2024
- 유형: 웹·Flutter 학습 서비스

## 촉촉박사
