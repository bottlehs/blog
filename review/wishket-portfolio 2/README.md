# 위시켓 포트폴리오 등록 검수 패키지

위시켓 서비스 점검이 끝난 뒤 등록할 27개 포트폴리오의 검수용 자료입니다.

## 공통 등록 규격

- 표지: 480 × 480px, PNG
- 상세 이미지: 최대 10장, 장당 8MB 이하, 가로 736px 권장
- 실제 화면이 있는 항목은 `source-screens/`의 원본 화면을 사용합니다.
- 타이핏·베베쿡·NIA 데이터 라벨링은 공개 화면 원본이 없어, 개념 시안 표지를 사용합니다. 실제 서비스 화면으로 표기하지 않습니다.

## 통일 표지 포맷

1. 프로젝트 실제 화면을 둥근 브라우저 또는 디바이스 프레임에 배치합니다.
2. 화면의 주색을 배경에 옅게 반영합니다.
3. 하단 고정 캡션에는 프로젝트명, 유형, 기간만 표기합니다.
4. 화면을 과도하게 생성·변형하지 않으며, 실제 프로젝트 스크린샷이 주인공이 되게 합니다.
