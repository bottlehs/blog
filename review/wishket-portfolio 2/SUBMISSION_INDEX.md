# 위시켓 수동 제출 인덱스

모든 프로젝트 폴더는 다음 형식입니다.

- `cover/cover-480.png`: 위시켓 **포트폴리오 표지 이미지**에 업로드할 통일 규격 이미지(480×480 PNG)

- `drafts.md`: 제목·기간·설명 원문 초안입니다.

## 공통 필드

- 업무 범위: 개발
- 참여율: 100%
- 역할: 풀스택 개발 (모바일 앱 중심 항목은 모바일 앱·풀스택 개발)

- 타이핏·베베쿡·NIA는 실제 화면 이미지가 없으므로, 임시 콘셉트 표지를 상세 이미지로도 사용해야 합니다.
- 고객사명·외부 연락처는 공개 입력란에 기재하지 않습니다.
- Bonivelo는 현재 위시켓에 중복 2건이 있으므로, 한 건을 남기고 다른 한 건을 삭제해야 합니다.
